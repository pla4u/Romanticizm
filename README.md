# Romanticizm — вокальный плагин (VST3 для FL Studio)

Звук «домашней комнаты»: близкий телефонный микрофон, мягкая лента, зерно, тёплый свет лампы и
лепестки в реверберации. Без автотюна.

## Как получить `Romanticizm.vst3` (Windows, без Visual Studio)
1. Загрузи **всё содержимое папки** в пустой репозиторий на GitHub (включая скрытую папку `.github`).
   Если загружаешь zip — сначала **распакуй** его.
2. Вкладка **Actions** → **Build Romanticizm** → при необходимости **Run workflow**. Сборка ~5–10 минут.
3. Когда появится зелёная галочка, открой запуск и скачай **Romanticizm-windows-vst3** (внизу, раздел Artifacts).
4. Распакуй скачанный zip. Внутри будет **`Romanticizm-Setup.exe`** — обычный установщик: запусти, нажми «Далее».
   Плагин встанет в `C:\Program Files\Common Files\VST3`, удалить можно через «Приложения» в Windows.
   Windows может показать синее окно «SmartScreen» (установщик без платной подписи): «Подробнее» → «Выполнить в любом случае».
   (Запасной вариант без установщика: `install_windows.bat` рядом с `Romanticizm.vst3`.)
5. FL Studio: **Options → Manage plugins → Find installed plugins**. Плагин называется **Romanticizm**.

## Цепочка
`Input → Body → Closeness / Lens → Phone → Velvet → Tape (Wobble · Colour · Drive) → Crunch → Twin → Echo ‖ Haze → Width → Mix → Limiter`

| Раздел | Ручки | Что делает |
|---|---|---|
| **Voice** | BODY, CLOSENESS, VELVET | BODY — форманты (ниже = «крупнее», выше = светлее), CLOSENESS — эффект близости к микрофону (бас-проксимити, мягкий верх), VELVET — мягкая компрессия + подавитель резкости |
| **Lens** | WARMTH, BITE, AIR, PHONE | Тембр. PHONE сужает голос до «диктофона в кармане» |
| **Mood** | XY-пад (лампа) | Одно движение: влево/вправо — **дальше от микрофона** (больше пространства), вверх/вниз — **состаренность** (плёнка, шум, зерно, насыщение). Двойной клик — в центр |
| **Tape** | DRIVE, WOBBLE, HISS, CRUNCH | Лента: насыщение, плавание скорости (wow/flutter), шипение и пыль, bit-crush. Кассета в углу крутится быстрее при WOBBLE |
| **Echoes** | TWIN, SPREAD, ECHO, FEEDBACK, TONE | TWIN — дублёр голоса, ECHO — ленточное/пинг-понг/стерео эхо, синхронно с темпом |
| **Haze** | HAZE, SIZE, TONE, BLOOM, PETALS | Реверб. BLOOM — реверб «приседает», пока ты поёшь, и расцветает в паузах. PETALS — вуаль на октаву выше |
| **Gloss** | GLOSS, WIDTH, DRIFT | Блеск верхов, ширина, разброс дублёра |

Шапка: **IN / OUT / MIX**, лампа-индикатор уровня, **LIMIT**, **BYPASS**, выбор пресета и темы.

Управление: тяни ручку мышью, двойной клик — сброс, колесо — точная подстройка.

## Темы
Sakura, Moss Tiles, Red Eye, Polaroid Sepia, VHS Night, Cyanotype — цветочные ручки, плёночный стиль.
**Cassette Deck** — кассетная дека: металл, ребристые ручки, фейдеры, светодиоды и стрелочный индикатор.
**Cherry Hearts** — ярко-красная тема: ручки-вишни в кольце из сердечек, лампы-сердца, чёрные завитки по бокам и анимированные ножки на сцене Mood.
Окно тянется за правый нижний угол.

## Пресеты
«Sorry, Ruined Your Party» (интимная комната), «Blurry Glow» (плотный и размытый), «Phone Memo», «Cherry Blossom»,
«Tape Lullaby», «Hyper Petal», «Red Eye», «Dry Velvet», «Blurry Sunday». Свои пресеты: `Documents\Romanticizm\Presets\*.rmz`.

## Технические детали
* Латентность ≈ 48 мс (FFT формант-шифтера), FL Studio компенсирует её сам. Для записи слушай себя напрямую, а не через плагин.
* Нагрузка ≈ 8 % одного ядра при 48 кГц. Все параметры автоматизируются.
* Тесты: `Tests/dsp_test.cpp` (`-DRMZ_BUILD_TESTS=ON`).
* Построен на JUCE (AGPLv3 / коммерческая лицензия): для личного пользования достаточно.
